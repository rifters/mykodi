# Jet Guide 

This document explains the available options when using the "Record/Play Stream" button in Jet Guide.

## [COLORblue]Usage Notes[/COLOR]

- You must have a stream currently playing in Kodi for these options to work.

- **[COLORblue]Settings Adjustment Required:[/COLOR]**  
  Before using these features, go to the addon's settings and configure the correct paths for mpv, ffmpeg, and your recording folder.  
  These settings are required for "Play Stream in mpv" and "Record Stream (ffmpeg)" to function properly.
- The "Record Stream" option is disabled on Android devices.


## [COLORblue]Options[/COLOR]

When you press the button, you will be prompted to choose one of the following actions:

1. **[COLORblue]Play Stream in mpv[/COLOR]**  
   Launches the currently playing stream in the external mpv player.

2. **[COLORblue]Record Stream (ffmpeg)[/COLOR]**  
   Records the currently playing stream using ffmpeg.  
   **Note:** This feature only works on PC (Windows). Recording is not supported on Android at this time.

3. **[COLORblue]Play Multiple Streams in mpv[/COLOR]**  
   Allows you to play multiple streams simultaneously in mpv.

4. **[COLORblue]Stop Recording[/COLOR]**  
   Stops the current recording session (if one is active).

5. **[COLORblue]Watch Recording[/COLOR]**  
   Opens the folder containing your recordings so you can watch previously saved streams.

6. **[COLORblue]Directions[/COLOR]**  
   Shows this help information in a dialog window.
